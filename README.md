# FUCKJESTER v1.0.0

**Автор:** jester
**Лицензия:** MIT

## Что это

Локальный OSINT-инструмент для работы с **собственными** базами данных
(утечки/дампы, которые загрузил сам пользователь) + генератор тестовых
личностей, паролей, ников и утилиты валидации.

## Возможности

1. **Загрузка баз** — .txt / .csv / .json / .rar (с защитой от path traversal),
   автоопределение кодировки и разделителей, потоковая обработка до 500 МБ,
   сохранение в SQLite.
2. **Поиск** — по телефону, email, ФИО, username, IP или любому тексту.
   Экспорт в CSV/JSON, rate limit 1 запрос / 2 сек.
3. **Генератор личностей** — 1500+ комбинаций на справочниках, полный профиль
   (ФИО, паспорт, ИНН, СНИЛС, карта, работа, образование, авто, Wi-Fi, соцсети
   и т.д.). Экспорт в TXT/CSV/JSON/HTML.
4. **Пароли** — сложные и запоминающиеся, оценка надёжности.
5. **Ники** — 4 стиля, проверка уникальности.
6. **Работа с базами** — список, удаление, объединение, дедупликация, экспорт.
7. **Утилиты** — валидация телефона/email/карты/ИНН, QR, vCard, AES-256.
